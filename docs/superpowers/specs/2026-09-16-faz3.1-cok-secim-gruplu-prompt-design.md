## 3. Kritik: keystroke karmaşıklığı (orca'dan KESİN)

Faz 3.0 tek-bayt keystroke kullandı (index → `0x31+i`). Faz 3.1 orca'nın **çok-adımlı,
pacing'li** keystroke akışını gerektirir. orca'nın kesin değerleri (bu oturumda çıkarıldı):

- **Sabitler** (`src/shared/native-chat-ask.ts`): `ASK_ENTER='\r'` (0x0d),
  `ASK_NEXT_TAB='\x1b[C'` (sağ ok), `ASK_PREVIOUS_ROW='\x1b[A'` (yukarı ok),
  `ASK_NEXT_ROW='\x1b[B'` (aşağı ok), `ASK_NOTES='\t'` (0x09).
- **Gruplu çok-soru tek-seçim:** her soru için `String(index+1)` (auto-advance), **sonda tek `\r`**.
  Örn: `[{indices:[1]},{indices:[2]}]` → `['2','3','\r']`.
- **Çoklu-seçim:** her toggle `String(index+1)`, sonra `'\x1b[C'` (Submit tab'ına), sonra `'\r'`.
  Örn indices [0,2] → `['1','3','\x1b[C','\r']`.
- **Free-text (Claude):** ayrı "Type something" satırı (PromptCard'da TextField).
- **Pacing:** gruplar **1000 ms** aralıkla PTY'ye yazılır (`NATIVE_CHAT_QUESTION_STEP_MS`).
  Faz 3.0'ın tek `writeInput`'u yetmez — RemoteService'e **zamanlı, iptal-edilebilir keystroke
  kuyruğu** eklenir (Faz 2 `FeedWatchdog`/Task kalıbı; test için enjekte saat/scheduler).
- **Codex** (`buildCodexAskAnswerKeys`): digit hem seçer hem gönderir (sonda `\r` YOK);
  free-text `\t` notes; cevapsız satır `\x7f` (backspace).

### orca keystroke algoritması (KESİN, port edilecek — `native-chat-ask.ts`)

`buildAskAnswerKeys(prompt, selections) -> [KeyGroup]` (KeyGroup = `.raw(String)` | `.text(String)`):
Her soru için (index qi), `sel = selections[qi]`, `other = sel.other?.trim()`, `typeSomething = String(options.count+1)`:
- **multiSelect:** her `i in sel.indices` → `.raw(String(i+1))`; other varsa `.raw(typeSomething), .text(other), .raw("\r")`; sonra `.raw("\x1b[C")` (Submit tab'ına — çok-soruda sonraki soru).
- **other (single-select):** `.raw(typeSomething), .text(answerLabels(q,sel).join(", ")), .raw("\r")`.
- **normal single-select (indices dolu):** `.raw(String(sel.indices[0]+1))`.
- **çok-soruda cevapsız:** `.raw("\x1b[C")` (adımla geç).
- **Son:** `endsOnSubmitTab = multiQuestion || (tek soru && multiSelect)` ise ve gruplar boş değilse `.raw("\r")`.

Sabitler: `ENTER="\r"`(0x0d), `NEXT_TAB="\x1b[C"`(sağ ok), `PREV_ROW="\x1b[A"`, `NEXT_ROW="\x1b[B"`, `NOTES="\t"`(0x09).
`answerLabels(q,sel)` = seçili option label'ları + trim'li other.

**Codex** `buildCodexAskAnswerKeys` (`:257-304`): note varsa en yakın satıra ok-nav + `\t`(NOTES) + text + `\r`; seçili index varsa `.raw(String(i+1))` (sonda Enter YOK, digit gönderir); cevapsız `\x7f`(DEL) + (orta soruda `\x1b[C`, sonda `\r`); herhangi cevapsız varsa sonda `\r`.

### Paced writer (RemoteService — YENİ, concurrency-sensitive)

Grup dizisi PTY'ye **1000 ms** aralıkla, iptal-edilebilir yazılır (orca `NATIVE_CHAT_QUESTION_STEP_MS=500+500`).
`.raw(s)` → `writeInput(Data(s.utf8))`; `.text(s)` → bracketed-paste (`\x1b[200~` + s + `\x1b[201~`) → writeInput.
- **Test için scheduler enjekte edilir** (`protocol KeystrokeScheduling { func schedule(after: Duration, _:) }`; fake = ani çalıştır). RemoteService @MainActor; kuyruk Task tabanlı, `.exited`/yeni-cevap/stop'ta iptal.
- prompt_respond geldiğinde önceki bekleyen kuyruk iptal edilir (çift-cevap koruması + revision guard, Faz 3.0).

## 4. Bileşenler (kesin)
- **`ChatPromptQuestion`** (LumiKit + mobil): `{id, question, header?, multiSelect, allowOther, options: [ChatPromptOption]}`.
- **`ChatPrompt`** additive (Faz 3.0 bozulmaz): `+ multiSelect: Bool = false`, `+ allowOther: Bool = false` (tek-soru); `+ questions: [ChatPromptQuestion] = []` (gruplu >1; tek-soru/approval'da boş). approval'a 3. seçenek `dont-ask` (id="dont-ask", keystroke orca'da "2"; §4.1 cihaz teyidi).
- **`PromptJournal`:** tek soru → flat + multiSelect/allowOther; gruplu (>1) → `questions` doldur. Codex event adları zaten tanınıyor.
- **`prompt_respond` payload (genişletilmiş):** approval → `{optionId}` (Faz 3.0). question → `{selections: [{indices:[Int], other:String?}]}` (soru sırasıyla). RemoteProtocol decode günceller.
- **`RemoteService`:** `buildAskAnswerKeys` port'u (LumiKit saf fonksiyon) + paced writer; prompt_respond → selections → keygroups → zamanlı writeInput → resolve+emit.
- **`MobileChatPromptCard`:** tek-soru multiSelect toggle+Submit(N), free-text TextField+gönder, approval 3. seçenek; gruplu tab bar + soru-soru stepping (EN SON task; orca `MobileNativeChatQuestion` + `advanceGroupedQuestion` referans).
